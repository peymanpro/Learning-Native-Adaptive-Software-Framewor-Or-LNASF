# Changelog

## 0.2.0 - 2026-10-11 — Research Proposal Draft

This release archives a working research proposal. It does not claim peer review, established novelty, or demonstrated performance improvements.

- Formalized the candidate LNASF Component Contract `LCC(C) = (B,O,M,P,G,A,F,E)` covering baseline behavior, observation, model updates, prediction evidence, adaptation admission, allowed actions, fallback/abstention, and outcome evaluation.
- Added a preliminary related-work comparison covering REX, ML-DEECo, machine-learning abstractions for component-based self-optimizing systems, Estimators, HAFLoop, FORMS, Rainbow, and prior usage of the learning-native software concept.
- Added DOI/official links and updated the bibliography.
- Added research questions and a proposed evaluation plan with deterministic baselines, gate ablations, safety/fallback checks, and adaptation-cost measurements.
- Added a compiled 13-page research draft PDF generated by GitHub Actions and reviewed for layout and reference overflow.
- Preserved the original Version 0.1 TeX/PDF as historical artifacts.
- Novelty remains a research question: the related-work analysis is preliminary, full-text comparison is incomplete, and controlled empirical evaluation has not yet demonstrated benefits.

## 0.1.0 - 2026-08-28

Initial technical concept and architecture specification.

- Defined Learning-Native Adaptive Software Component (LNASC).
- Defined the Observe -> Learn -> Predict -> Decide -> Adapt -> Measure -> Learn loop.
- Defined native-learning and scratch-learning principles.
- Separated prediction, decision, confidence, utility, safety constraints, and adaptation.
- Defined deterministic fallback behavior.
- Defined parameter, strategy, and structural adaptation levels.
- Defined passive, advisory, adaptive, and autonomous operating modes.
- Defined local, shared, and hybrid learning scopes.
- Mapped potential frontend, backend, runtime, and infrastructure applications.
- Documented relevant prior art and references.
